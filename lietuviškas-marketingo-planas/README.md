## 🌟 Projekto Apžvalga

**Darbo Portalas** - tai pažangi, daugiakalbė darbo paieškos platforma, sukurta naudojant modernias technologijas (Laravel 12, Vue.js 3, TailwindCSS). Sistema palaiko 9 kalbas, įskaitant lietuvių ir rusų kalbas.

### Pagrindinės Charakteristikos
- 🌐 **9 kalbų palaikymas**: Anglų, arabų, vokiečių, ispanų, prancūzų, portugalų, rusų, turkų, kinų
- 👥 **3 vartotojų tipai**: Administratoriai, darbdaviai, darbuotojai
- 💼 **Pilna darbo valdymo sistema**
- 🏢 **Išsami įmonių valdymo sistema**
- 📱 **Responsive dizainas** su TailwindCSS
- 🔒 **Saugios autentifikacijos funkcijos**
- 💳 **Integruotos mokėjimo sistemos** (Stripe, PayPal, Paystack)

## 🎯 Marketingo Strategija

### Tikslinės Auditorijos

#### 1. Darbdaviai / HR Specialistai
- **Amžius**: 25-55 metai
- **Pozicijos**: HR vadovai, personalo specialistai, įmonių savininkai
- **Poreikiai**: Efektyvus talentų paieška, CV valdymas, aplikantų filtravimas

#### 2. Darbo Ieškantys Asmenys
- **Amžius**: 18-65 metai
- **Kategorijos**: Absolventai, karjeros keitėjai, kvalifikuoti specialistai
- **Poreikiai**: Tinkamų darbo vietų paieška, karjeros plėtojimas

#### 3. Savarankiškai Dirbantys / Freelanceriai
- **Amžius**: 20-50 metų
- **Sritys**: IT, dizainas, rašymas, konsultavimas
- **Poreikiai**: Projektų paieška, lankstūs darbo grafikai

### Marketingo Kanalai

#### Skaitmeniniai Kanalai
1. **SEO Optimizacija**
   - Raktiniai žodžiai: "darbo paieška Lietuvoje", "IT darbo vietos", "karjeros galimybės"
   - Meta aprašymai 9 kalbomis
   - Lokalus SEO miestams ir regionams

2. **Google Ads Kampanijos**
   - Tikslinės reklamos darbo ieškančiams
   - Retargeting darbdaviams
   - YouTube video reklamos

3. **Socialiniai Tinklai**
   - LinkedIn (B2B marketingas)
   - Facebook (platesnė auditorija)
   - Instagram (jaunesnė auditorija)

4. **Content Marketing**
   - Karjeros patarimai blog'e
   - Pramonės įžvalgų straipsniai
   - Sėkmės istorijos

#### Tradiciniai Kanalai
1. **Verslo Renginiai**
   - Karjeros mugės
   - HR konferencijos
   - Technologijų renginiai

2. **Partnerystės**
   - Universitetai ir kolegijos
   - Profesinės asociacijos
   - Rekruitavimo agentūros

## 💻 Techninis Planas

### Backend Technologijos
- **Laravel 12** - naujausia versija su moderniais funkcijais
- **PHP 8.3** - optimizuotas našumas
- **MySQL 8.0** - duomenų bazės valdymas
- **Redis** - cache ir sesijų valdymas
- **Elasticsearch** - spartinė paieška (planuojama)

### Frontend Technologijos
- **Vue.js 3** - modernūs komponentai
- **TypeScript** - tipų saugumas
- **TailwindCSS** - utility-first CSS
- **Vite** - greitasis development server
- **Pinia** - state valdymas

### Infrastruktūra
- **Docker** - konteinerizavimas
- **Nginx** - web server
- **Let's Encrypt** - SSL sertifikatai
- **AWS/DigitalOcean** - hosting sprendimai
- **CDN** - statinio turinio pristatymas

### Saugumas
- **Laravel Sanctum** - API autentifikacija
- **Spatie Permissions** - rolių valdymas
- **Rate Limiting** - API apsauga
- **CSRF apsauga** - Cross-site request forgery
- **SQL Injection apsauga** - Eloquent ORM
